# VoiceControl Agent

VoiceControl - это голосовой агент для управления компьютером с помощью голосовых команд. Проект реализует систему распознавания речи, обработки команд и синтеза речи.

## Основные функции

1. **Распознавание речи**: Осуществляет распознавание голосовых команд
2. **Воспроизведение речи**: Генерирует голосовые ответы для пользователя
3. **Обработка команд**: Интерпретирует команды и выполняет соответствующие действия
4. **Управление системой**: Выполняет системные команды через специальный обработчик

## Установка и запуск

### Требования

- Python 3.7+
- Звуковая карта с микрофоном
- Установленный `pip`

### Установка зависимостей

В системе может возникнуть проблема с установкой PyAudio из-за необходимости компиляции. Для решения проблемы:

1. Попробуйте установить предварительно скомпилированную версию:
```bash
# Сначала установите основные зависимости
pip install SpeechRecognition pyttsx3

# Для PyAudio попробуйте установить из wheel-файлов:
pip install pipwin
pipwin install PyAudio
```

Если вышеуказанный метод не работает, используйте следующую альтернативную установку:

```bash
# Загрузите .whl файл PyAudio вручную с сайта: 
# https://www.lfd.uci.edu/~gohlke/pythonlibs/#pyaudio
# Например:
pip install PyAudio‑0.2.11‑cp315‑cp315m‑win_amd64.whl
```

### Запуск агента

```bash
python src/voicecontrol/main.py
```

## Конфигурация

Конфигурация хранится в файле `config.py` и может быть изменена для настройки:

- `wake_phrase`: Ключевое слово для активации агента (по умолчанию: 'voice control')
- `language`: Язык (по умолчанию: 'ru')
- `sample_rate`: Частота дискретизации (по умолчанию: 16000)
- `chunk_size`: Размер фрагмента данных (по умолчанию: 1024)

## Команды агента

Агент поддерживает следующие команды:

- "открой браузер" - открывает стандартный веб-браузер
- "включи музыку" - воспроизводит музыку с помощью медиаплеера
- "какая погода" - проверяет интернет-соединение
- "погаси свет" - имитация управления освещением
- "запусти виндовс" - имитация запуска ОС Windows
- "получи информацию о системе" - выводит информацию о системе

## Системные требования

- Рабочая микрофонная система (PyAudio)
- Установленный синтезатор речи (pyttsx3)
- Поддержка библиотек SpeechRecognition и pyttsx3

## Важные примечания

### Проблема с PyAudio на Windows
В некоторых случаях установка PyAudio может вызвать проблемы на Windows из-за необходимости компиляции. В этом случае:

1. Сначала установите `pipwin`:
   ```bash
   pip install pipwin
   ```

2. Затем попробуйте установить PyAudio через pipwin:
   ```bash
   pipwin install PyAudio
   ```

3. Если этот способ не работает, скачайте файл `.whl` для PyAudio с сайта: https://www.lfd.uci.edu/~gohlke/pythonlibs/#pyaudio

### Альтернативный подход для отладки
Если установка PyAudio не удаётся, вы всё равно можете запускать тесты и проверять код, используя специальные функции без необходимости фактической работы с аудио:

```bash
python run_test.py
```

Этот скрипт проверяет, что все модули могут быть импортированы корректно.

## Доработка

Проект легко расширяем. Для добавления новых команд:

1. Добавьте новую функцию в `command_handler.py`
2. Обновите `dispatcher.py` для маршрутизации новой команды
3. Обновите документацию с описанием новой функции
