### Проверки этого среза

- `python -m pytest -q -p no:cacheprovider`: **153 теста прошли**; один FutureWarning от comtypes на Python 3.15.
- Синтаксис 26 Python-файлов: 25 без замечаний; `parser.py` падает на BOM при `compile(read_text('utf-8'))`.
- Установлены `pytest`, `SpeechRecognition`, `pyttsx3`; не установлены `PyAudio`, `NumPy`, `whisper`, `faster-whisper`, `yaml`.
- `main.py`: в production-режиме запуск блокируется с кодом 1, в тестовом режиме возвращает 0 и рабочий цикл не запускает.
- `shell=True` в `src/` отсутствует; `run_command` использует `shell=False`, `dry_run` включён по умолчанию.
- Агент намеренно не запускался.

## Правила работы модели

- [ ] Перед изменениями изучить текущие файлы, конфигурацию, зависимости и тесты.
- [ ] Найти первый незавершённый этап в техническом задании; не переписывать готовое и не перескакивать этапы.
- [ ] До изменений сообщить цель этапа, список файлов и планируемые зависимости.
- [ ] Выполнять только один этап за раз и остановиться после отчёта, дождавшись подтверждения пользователя.
- [ ] Не считать наличие файла, класса или функции доказательством готовности — проверить реальный путь выполнения и тесты.
- [ ] Не добавлять случайные результаты, фиктивные действия, заглушки или сообщения об успехе без выполненного действия.
- [ ] Использовать моки и dry-run только в тестах/разработке; они не должны незаметно включаться в рабочем режиме.
- [ ] Сохранять несвязанные изменения и не менять файлы вне текущего этапа без необходимости.
- [ ] Запускать только релевантные проверки и указывать их фактические результаты.
- [ ] Не выполнять опасные действия на настоящей системе во время тестов.

- [x] При ошибке действия возвращается ошибка, а не ложный успех.
- [x] Тесты используют моки/dry-run и не выполняют системные операции на машине.

## Этап 7 — wake phrase и сквозной цикл

- [ ] Wake phrase обнаруживается по аудио, а не случайным числом.
- [ ] Рабочий цикл связан в порядке: ожидание активации → запись → распознавание → разбор → безопасное выполнение → голосовой ответ.
- [ ] Команда, произнесённая сразу после wake phrase или вместе с ней, не теряется.
- [ ] Подтверждение опасной операции ожидает реальный голосовой ответ с таймаутом.
- [ ] Цикл ожидает аудио/событие и не создаёт активную загрузку или бесконечный поток логов.
- [ ] Остановка агента корректно закрывает микрофон, TTS и прочие ресурсы.
